# wokanoka — Mad Rat Cafe website

Static site (plain HTML, CSS and JavaScript). No build step.

- `index.html` — home page
- `press-kit/index.html` — press kit page (the ZIP is hosted in GitHub Releases, tag `press-kit`)
- `assets/css/style.css` — styles and colour tokens
- `assets/js/main.js` — mobile menu, lazy trailer, gameplay loops
- `assets/img`, `assets/video` — web copies of the media
- `assets/fonts` — Inter and Jersey 10 (SIL Open Font License, see `OFL-*.txt`)
